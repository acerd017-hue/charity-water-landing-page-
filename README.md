# Charity: Water Landing Page

## Project Overview

A responsive landing page inspired by charity: water's mission
to help communities gain access to clean and safe drinking water.

## Features

- Full-screen hero image with text overlay
- Clear call to action linking to charity: water
- Responsive design for mobile and desktop
- Accessible text contrast and keyboard focus styles
- Custom brand color palette

## Brand Colors

- Signature Yellow: #FFC700
- Teal: #00A19D
- White: #FFFFFF

## Typography

Proxima Nova is the preferred typeface. Similar sans-serif
fonts are used as fallbacks if Proxima Nova is unavailable.

## Technologies

- HTML5
- CSS3
- GitHub Codespaces
- GitHub Pages

## Run Locally

Open index.html using a local development server,
or use the Live Preview extension in Codespaces.

## Image Credits

The hero image was supplied for this project.
Replace it only with an image you have permission to use.
